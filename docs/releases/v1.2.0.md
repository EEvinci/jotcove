# 笺湾 · JotCove v1.2.0

散落的灵感，在这里靠岸。

## 全新的名字与图标

- 产品正式更名为“笺湾 · JotCove”，由 Evinci 开发与维护。
- 全新可可棕应用图标：米白折纸、雾霾蓝收纳弧线与暖黄圆点。
- 配套菜单栏单色标记、中文与英文品牌字样。
- 统一欢迎页、菜单、设置、截图导出名、源码 target、Xcode 工程及安装包名称。
- 更新 README、架构说明、截图和品牌资源说明。

## 下载与升级

下载 `JotCove-1.2.0.zip`，先退出旧版，再解压并把 `JotCove.app` 拖入「应用程序」。应用支持 macOS 15+，同一个通用包支持 Intel 和 Apple 芯片。

新名字沿用原来的历史目录与应用内部标识，已有剪贴板记录和设置无需重新导入。旧版与新版请勿同时运行。应用没有自动批量改写已有内容；先前保存在历史里的文字和标题仍保留原样。

本次为 ad-hoc 本地签名，**未经 Apple 公证**。首次打开、屏幕录制和辅助功能权限步骤见包内 `FIRST-LAUNCH.txt`。若系统要求重新授权，请按提示处理。

源代码开发入口变为 `JotCove.xcodeproj`，选择 `JotCove → My Mac` 运行。不要继续用旧工程或 SwiftPM 裸可执行文件作为日常 App 调试入口。

更名前的源码保留在 `backup/pre-jotcove-2026-10-26`，v1.1.0 发布包继续保留。

JotCove is the new name for this project. This Universal build supports macOS 15+ on Apple silicon and Intel, preserves the existing history and settings identity, and is ad-hoc signed without Apple notarization. Quit the old app before opening JotCove.
