# Pastory v1.1.0

Pastory 将剪贴板历史、截图标注、本地文字识别、录屏与桌面便签收进一个 Mac 原生工作空间，由 Evinci 开发与维护。

## 本次发布

- 可可棕、雾霾蓝与米灰的纸感界面，融入个人 IP 与头像。
- 统一产品介绍、作者信息和安装说明。
- 提供完整的 Xcode App 工程，日常调试可直接运行 `.app`，包含真实应用标识、字体和人物素材。
- 更新中英 README，增加面向非技术读者的架构说明与对外介绍稿。
- 提供同时支持 Apple 芯片与 Intel 的 macOS 安装包，并附首次打开说明与 SHA-256 校验文件。

## 下载与安装

1. 下载 `Pastory-1.1.0.zip` 并解压，把 `Pastory.app` 拖到「应用程序」。
2. 需要 macOS 15 或更新版本。启动后点击菜单栏图标，或按 ⇧⌘V 打开剪贴板面板。
3. 此发布使用本地 ad-hoc 签名，**未经 Apple 公证**。如 macOS 阻止打开，请按压缩包内的 `FIRST-LAUNCH.txt`（首次打开说明），在「系统设置 → 隐私与安全性」允许打开。
4. 首次截图/录屏需要屏幕录制权限；双击直接粘贴需要辅助功能权限。只复制内容无需辅助功能权限。

## 使用边界

- 数据保存在本机；无需账号，没有云同步或在线更新检查。
- 当前录屏不录系统声音和麦克风声音。
- 支持关键词搜索，暂不提供语义搜索。
- 升级时先退出旧版；同一个数据目录不要同时运行多个实例。
